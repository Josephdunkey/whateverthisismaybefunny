## 已修改

1. **learned 语义**
   - 只有 book card 为 `verified/complete` 且至少有一个 framework 的书才进入 learned。
   - 启发式 compile 只算 `ingested`，不会冒充“已学会”。
   - MCP 的 `book_library` 也按同一规则返回 `learned`。

2. **claims 重建保护**
   - `replace_claims()` 只替换未复核的 `active/conflicted` claims。
   - `superseded/retracted` 或带 resolution 的人工复核记录会保留。
   - `detect_conflicts()` 不会把人工 dismiss 过的冲突重新生成。

3. **claim graph 进入回答链路**
   - `create_analysis()` 会按问题检索 claims，把逐字 quote 加入 evidence。
   - 真实 claim 冲突会写进 `cross_lens_conflicts`，没有时才用模板提示。
   - memo 新增 `Claim graph` 表格。

4. **模型与检索性能**
   - embedding backend 和 reranker 改为进程级缓存，避免每次检索重载模型。
   - chunk rows、query vector、embedding matrix、quality score 增加版本化缓存。
   - embedding 打分改用 numpy 矩阵乘法；numpy 不可用时回退 cosine 循环。
   - 修复 lazy backfill 后版本号过期、导致只覆盖一本书的回归。

5. **批量选书**
   - `select_books()` 不再对每本书各跑一次全库混合检索。
   - 改成一次批量检索，再按 `book_id` 分组取前 3 条。
   - 方向模式复用选择理由，不重复做方向检索。

6. **诊断**
   - 新增 `bookcompiler doctor`：Python/venv、依赖、active embedding、覆盖率、reranker、learned 数量、Hindsight 连通性。
   - 修复懒加载神经模型在 doctor 里显示 `dim=0` 的问题。

7. **reranker 默认策略**
   - `.env` 默认 `BOOKCOMPILER_RERANK=0`。
   - 需要时用 `--rerank` 或显式改回 `1`；不再默认拖慢每次检索。

8. **测试**
   - 新增 `tests/test_improvements.py`。
   - 覆盖：启发式不算 learned、复核 claim 保留、claim 进入 analysis、批量选书、embedder 单例。
   - 当前：`60 passed`（含新增 reading/Obsidian 测试）。

## 仍然要诚实说的话

这仍然不是“读一本就自动变成专家”的魔法。它现在是一个**可引用、可审计、可回滚的书库能力层**：书 → chunk/向量/实体/claim → 选书 → 带引用分析。它比普通 RAG 多了框架、实体、claim、反馈和受控演化，但 claim 质量、跨书语义对齐、真实盲评和自进化数据都还需要继续积累。

下一轮优先级：

1. 在确认 claim 抽取质量后，只重建 4 本 learned 书的 claims，并做人工/agent 抽样复核。
2. 把剩余 8 本 ingested 书逐本编译成带逐字引用的 BookCard/FrameworkCard。
3. 建立 20 条事件级盲评集，校准混合权重、切块和 reranker。
4. 补 claim 条件、时效、跨书冲突复核和显式 supersession。
5. 用真实 feedback 驱动 evolution proposal，跑 shadow/canary，而不是只看结构 replay。

## 追加：权威信息源缺口提示（Source Gaps）

这一轮解决的是“学科覆盖不等于权威原文覆盖”的问题。真实库有中央银行教材、财政学材料和政治法律书，但没有《中国人民银行法》《商业银行法》《银行业监督管理法》等一手法规；旧逻辑只看 `law` 标签，于是错误地显示 `Coverage gaps: None detected`。

### 新增

1. **`src/bookcompiler/source_gaps.py`**
   - 内置权威信息源目录；
   - 按 query/direction 关键词命中；
   - 检查书库是否已有同名或近同名标题（包括尚未编译的 ingested 书）；
   - 返回 `source_recommendations`，含优先级、原因、命中词、建议学科、官方来源、入库命令和 next check。

2. **选择链接入**
   - `SelectionProposal.source_recommendations`（默认空列表，兼容旧数据）；
   - `build_proposal()` 自动生成；
   - `create_analysis()` 写入 `selection.source_recommendations`，并把入库提醒加入 `next_checks`。

3. **输出接入**
   - Markdown 选择卡和 memo 新增 `Suggested sources to download and ingest`；
   - CLI 新增 `source-gaps --query ... --lenses ... --format text/json`；
   - MCP `book_plan` / `book_analyze` 返回 `source_recommendations`，并更新工具描述，要求 agent 明确转告用户；
   - Web GUI 选择卡和已保存分析视图新增“信息源缺口提示”卡片。

4. **首批目录**
   - 中国人民银行法
   - 商业银行法
   - 银行业监督管理法
   - 预算法
   - 预算法实施条例
   - 立法法
   - 国发〔2014〕43号
   - 商业银行资本管理办法
   - 商业银行流动性风险管理办法

### 行为边界

- 不自动联网下载；
- 不把未入库的法规写进 citations；
- 书库已有同名法规时不重复提示下载；
- 目录是保守起点，后续按领域扩充，不让模型自由编造法规名。
