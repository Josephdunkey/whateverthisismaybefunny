## 2. 读书链路修复

1. **DeepSeek 费用硬闸**：`_reader_config()` 只要解析到 DeepSeek 端点就报错，除非显式设置
   `BOOKCOMPILER_READER_ALLOW_DEEPSEEK=1`。CLI 的 `--provider/--model/--base-url`
   也走同一函数，不能绕过。
2. **Schema 容错**：MiMo 有时把 `frameworks` 嵌在 `book_card` 里，或包在 `book/result/data`
   外层。`normalise_patch()` 现在会解包，不再静默产生 0 个框架。
3. **安全拒绝可诊断**：MiMo 返回 `status=rejected` / `high risk` 时抛出 `ReaderRefused`，
   不做无意义的 JSON repair 重试；prompt 增加“授权学术编译任务”的说明。
4. **重复段落引用误报**：OCR 书里同一段可能出现在两页。校验器现在优先核对
   citation 自己指向的 chunk；只有该 chunk 不含 quote 时才全局查找，避免假 warning。
5. **CLI 超时修复**：`compile-llm` 的模型覆盖现在也读取
   `BOOKCOMPILER_READER_TIMEOUT`，本地 Ollama 长任务不会在 120 秒被误杀。
6. **中英术语桥**：中文问题会自动追加英文对应词（逻辑→logic、谬误→fallacy、
   法律→law 等），并对英文段落加 0.25 的桥接分。中文问“逻辑谬误与法律论证”现在能召回
   《Introduction to Logic》。
