2. 总体架构 不要把三套系统想成一坨。它们是三个独立的进程/服务，通过文件和网络接口连接。 用户 ├─ 浏览器 → BookCompiler GUI（127.0.0.1:8765） │ ├─ SQLite：library.db │ │ ├─ 书 / chunk / 原文 │ │ ├─ 向量（chunk_embeddings） │ │ ├─ 书卡 / 框架卡 / 分析 │ │ ├─ 实体 / 提及 / 关系 │ │ ├─ 命题 / 证据 / 冲突 │ │ └─ 反馈 / 记忆 / 进化状态 │ └─ HTTP → Hindsight（127.0.0.1:8888） │ ├─ Hermes Agent（D:\hermes agent） │ ├─ SQLite：state.db（会话、消息、系统提示、状态） │ ├─ MCP stdio → BookCompiler（15 个工具） │ ├─ MCP HTTP → Hindsight /mcp/hermes/（36 个工具） │ └─ MCP HTTP → Hindsight /mcp/bookcompiler/（36 个工具） │ ├─ Hindsight API（127.0.0.1:8888） │ ├─ 内嵌 PostgreSQL（127.0.0.1:5432） │ │ ├─ 数据库：hindsight │ │ ├─ 扩展：pgvector 0.8.5 │ │ └─ 数据目录：C:\Users\mybea\.pg0\instances\hindsight\data │ └─ 调用 Ollama（127.0.0.1:11434） │ └─ qwen2.5:7b-instruct-q4_K_M │ └─ Ollama（127.0.0.1:11434） └─ 模型文件：D:\models（blobs / manifests） 三条数据流 书 → 证据： 书被导入 BookCompiler，切成 chunk，建 BM25 和向量索引。回答书里的内容时，必须从这里取原文。 经验 → 记忆： 用户反馈、纠正、偏好写入 BookCompiler 的 feedback/memory，并异步写入 Hindsight 的 bookcompiler bank。 对话 → 调用： Hermes 根据问题调用 BookCompiler 工具，必要时再调用 Hindsight 召回长期偏好，最后组织回答。 关键设计： 书里的原文和精确引用永远留在 BookCompiler 的 SQLite；Hindsight 只存“跨任务可复用的教训/偏好”，不存整本书。这样不会把“记忆”变成“二手摘要”，也不会让模型拿记忆冒充原文。

===== s15: 15. 自进化是什么、不是什么 (861 chars) =====
15. 自进化是什么、不是什么 15.1 它现在能做什么 从结构化反馈中生成 proposal：错误模式、偏好书/框架、缺失证据、低分分析。 提案有 evidence_feedback_ids、risk、rollback、gate。 状态机： proposed → accepted → shadow → promoted → rolled_back ，也可以 rejected 。 晋升必须有结构回放报告，且所有 case 通过。 应用前写快照，失败可恢复；支持 rollback。 只允许三类变更：检索权重、书偏好、框架偏好。 15.2 它不能做什么 不会自动改写 BookCard、FrameworkCard、引用或代码。 不会自动改逐字引用校验规则。 不会因为一次低分就把某本书永久拉黑。 不会在没有回放报告的情况下晋升。 不会做真正的 shadow/canary 流量和盲评（还没实现）。 15.3 为什么这么保守 书籍分析系统最危险的不是“回答不够聪明”，而是“编造引用”“把某本书的观点压成错误口号”“把框架用在不适用的条件下”“把三个镜头的冲突平均掉”。所以真值契约不能学习：引用校验、法律免责声明、冲突处理规则必须固定。 15.4 当前状态 本机书库目前 feedback=0 、 evolution_proposals=0 ，所以自进化链路还没有用真实反馈跑过。代码和测试在，但没有“已经进化出更好配置”的证据。不要声称它已经通过自进化变强。 15.5 怎么试 对一份分析打分并写反馈（GUI 分析详情底部，或 CLI feedback ）。 运行 evolution-propose --min-support 1 。 查看 proposal，决定 accept / reject。 如果 accept，进入 shadow；准备回放 cases。 回放全通过后，才能 promote。 不满意就 rollback。 记住：结构回放通过只证明“没有结构退化”，不证明“答案质量更好”。真正的盲评还没做。
